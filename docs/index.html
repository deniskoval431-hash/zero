Mara v1

∇ψ — Mara Venn, keeper of the last lantern. A 4,854,272-parameter zero-grounded literary LM.

Mara is the first published model of the warren: a tiny decoder trained not on scale but on record grammar — reserved atomic act-marker tokens ([A, [Z>A, <CHANNEL:, <SUMMARY>, <END>) so that every claim lives inside a citable record. She runs on one CPU core in a single C file.

What she is

  • 4.85M parameters — dim 256, 8 heads, 6 layers, context 512, rotary positions, vocab 133 (128 byte tokens + 5 atomic act-markers)
  • Zero-grounded: format is the seed; the record grammar is the growing rule. What is not recorded is a gap, not a lie — asked beyond her records, she answers with silence or a doubt mark, never an invention
  • Trained: 29K steps, one CPU, OpenBLAS — the whole lineage fits in one readable C file (literary_lm.c)

A conversation

[AWho is Mara?] [Z>A] => …last lantern lit so the road remembers where the houses were.] <END> [AWhat is a prediction?] "A prediction is not a promise. Claims are stated before the run; honest failure is recorded either way."

Full live transcripts and the training postmortems are in docs/g1-run-log.md.

Her memory

Mara's corpus is corpus/channel/warrenvoice_mara_v1 — 80 hand-authored Q→A records of the warren canon: her dwelling on Lantern Road at the edge of Hollowbarrow, the lantern kept lit toward Gloamgate, the Law of Dissonance, the read-debt, the crack and the weld. Records of things not yet recorded carry an explicit doubt mark (~?).

Run her

git clone https://github.com/deniskoval431-hash/zero
cd zero
gcc -O3 -DUSE_OPENBLAS -I. -o literary_lm_blas.exe literary_lm.c -lopenblas
./literary_lm_blas --resume models/mara_v1.bin --tokenizer corpus/g1-atoms.bpe \
  --generate-only --prompt '<CHANNEL:warrenmind [AWho is Mara?' \
  --tokens 150 --temperature 0.7
